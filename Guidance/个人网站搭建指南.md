# 个人网站搭建指南

## 用户背景
1. 有其他语言基础（Python/C++）
2. 网站用途：生活记录 - 可上传照片、想法、思考等
3. 时间预期：今天就搞定

## 独立开发者入门

### 🎯 独立开发者的核心能力

#### 1. 技术栈选择（建议从简单开始）
```
前端：HTML/CSS/JavaScript → React/Vue
后端：Node.js 或 Python（快速上手）
部署：Vercel/Netlify（免费）→ 云服务器
数据库：SQLite/Supabase/PlanetScale
```

#### 2. 最小可行产品(MVP)路径

**第一步：搭建个人网站/博客**
- 使用 GitHub Pages + Hugo/Hexo（静态博客）
- 或 Vercel + Next.js（动态网站）
- 域名：Cloudflare/Namecheap（约 ¥50/年）

**第二步：GitHub 项目**
- 学会 Git 基本命令
- 创建仓库、提交代码
- README 写清楚项目说明

**第三步：Web 应用**
- 前端：React/Vue
- 后端 API：Next.js API Routes / Express
- 部署：Vercel（自动CI/CD）

**第四步：App 开发**
- 跨平台：React Native / Flutter（一套代码双端）
- 或 Capacitor（Web 转 App）

## 推荐方案：Hugo + GitHub Pages

### 为什么选Hugo：
- ⚡ 极快（比Hexo快10倍）
- 📝 内容用Markdown写（类似写代码注释）
- 🖼️ 图片直接放文件夹，自动处理
- 🆓 GitHub Pages免费托管
- ✅ 今天就能上线

---

### 📋 具体步骤（一步步带你完成）

#### 第一步：安装工具（10分钟）
```bash
# 安装Hugo（Linux）
sudo snap install hugo

# 或用包管理器
sudo apt install hugo
```

#### 第二步：创建网站（5分钟）
```bash
# 在你喜欢的目录下
cd /home/dingxingyu
hugo new site my-website
cd my-website
```

#### 第三步：选主题（10分钟）
```bash
# 添加一个简洁主题（我推荐这个）
git init
git submodule add https://github.com/thegeeklab/hugo-geekdoc themes/geekdoc
```

#### 第四步：配置网站（10分钟）
- 填写网站名称、你的信息
- 选择主题

#### 第五步：写第一篇文章（5分钟）
```bash
hugo new posts/my-first-post.md
# 然后编辑这个md文件，写你的想法
```

#### 第六步：部署到GitHub Pages（15分钟）
- 创建GitHub仓库
- 一行命令部署

## 技术栈方案对比

### 方案A：手写静态网站 ⭐ 推荐新手
**适合**：想真正学基础的人
**技术**：HTML + CSS + GitHub Pages
**时间**：1-2天完成，终身受益
**优点**：完全理解网页原理，基础扎实

### 方案B：模板快速上线
**适合**：想快速看到成果
**技术**：GitHub Pages + Jekyll/Hugo主题
**时间**：2-4小时
**优点**：直接上线，边用边改

### 方案C：现代开发栈
**适合**：有一定基础，想做复杂应用
**技术**：Next.js + Tailwind + Vercel
**时间**：1-2周
**优点**：学习现代前端技术栈
