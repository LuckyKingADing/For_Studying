# 英文论文技术报告生成提示词

---

## 使用说明

将以下提示词发送给 AI，即可获得一份完整的、结构化的英文论文技术分析报告。

---

## 完整提示词

```
请帮我对这篇英文论文生成一份完整的中文技术分析报告，并写入到 md 文档中。

具体要求如下：

### 1. 忠于原文，不添加未在论文中出现的内容

报告中的每一个数字、结论、实验配置必须来自论文原文。请在生成后自查：
- 作者/机构信息是否与论文一致
- 所有公式编号和形式是否与原文一致
- 实验数据（表格中的数字）是否与原文完全一致
- 消融实验的增减项是否正确

### 2. 报告结构要求

报告应包含以下章节：

一、一句话概括（1-2 句话提炼论文核心贡献）
二、背景与问题
  - 1.1 研究领域现状
  - 1.2 现有方法的缺陷（用表格呈现）
  - 1.3 本文核心贡献（用 ASCII 架构图呈现）
三、核心技术方法
  - 2.1 问题建模（输入、输出、训练目标公式）
  - 2.2 核心方法A（含公式推导和流程图）
  - 2.3 核心方法B（含公式推导和流程图）
  - 2.4 整体训练损失（用表格列出所有损失项及权重）
四、实验设置与结果
  - 3.1 实验配置
  - 3.2 开环评估（表格 + 关键发现）
  - 3.3 闭环评估（表格 + 关键发现）
  - 3.4 消融实验（表格）
五、创新点总结（用编号列表，每个创新点有具体描述）
六、局限性与可能改进方向
七、与其他工作的关系（用表格或架构图呈现）
八、总结
九、附录：核心公式速查表

### 3. 图的详细视觉说明（关键要求）

对于论文中的每一张图（Figure 1, Figure 2, ...），请在报告末尾增加一个独立的"论文原图详细视觉说明"章节，为每张图补充以下内容：

#### 每个 Figure 需要提供：
- **原文标题**：论文中对该图的完整标题
- **原文说明**：论文中的 caption 原文
- **视觉结构解读**：用 ASCII 图表详细描述图中可见的视觉元素，包括：
  - 整体布局（横向/纵向/多列等）
  - 每个模块/组件的视觉外观和标注
  - 箭头/连线的含义（实线/虚线/不同颜色）
  - 标注文字的位置和内容
  - 图例说明（每种线型/颜色/形状代表什么）
- **数据流向**：如果涉及信息流动，用箭头清晰标注方向
- **实验意义**：该图验证了什么结论，与正文哪些段落对应
- **统计意义**：如果有图表数据（柱状图、折线图、分布图等），解释其统计含义

#### ASCII 图表规范：
- 使用 Unicode 字符绘制框架（┌─┐│└─┘）
- 使用 → ← ↑ ↓ 表示数据流向
- 使用不同符号区分不同元素：
  - 虚线框表示可选/特权信息
  - 粗线表示主要数据流
  - 颜色标注（如 红色/蓝色）在括号中说明
- 每个模块内部标注输入输出

### 4. 自查清单

生成完报告后，请对照以下清单检查：

□ 所有公式编号与原文一致
□ 所有表格数字与原文一致
□ 作者/机构/发表时间信息准确
□ 没有编造原文未提到的数据
□ 每张图都有详细的视觉描述
□ 核心创新点表述准确
□ 局限性分析有原文依据

### 5. 格式规范

- 公式使用 LaTeX 格式（$...$ 行内，$$...$$ 块级）
- 表格使用 Markdown 语法
- 层级标题使用 ## 和 ### 区分
- 重要结论用引用块（>）呈现
- 术语首次出现时给出英文原文
- 代码块中不使用行号
```

---

## 各要求的设计理由

| 要求 | 理由 |
|------|------|
| **忠于原文** | 避免 AI 幻觉，确保技术报告的学术准确性 |
| **结构化章节** | 便于阅读和导航，与已建立的 SLAM 系列报告风格一致 |
| **图解详细说明** | 原图无法直接嵌入 MD 时，提供完整的文字版视觉还原 |
| **自查清单** | 减少错误遗漏，确保数据引用的可靠性 |
| **LaTeX 公式** | 数学表达式规范呈现，便于理解算法细节 |

## 快速使用版本

如果需要更简洁的提示词，可以用以下版本：

```
请为这篇英文论文生成一份完整的中文技术分析报告（Markdown格式）。

要求：
1. 所有内容必须忠于原文，数字/公式/结论必须与论文一致
2. 包含以下章节：背景问题、核心技术方法（含公式推导）、实验结果、创新点总结、局限性
3. 对论文中的每张图，在附录中添加详细的ASCII视觉结构图，包括：整体布局、模块标注、数据流向、图例说明
4. 生成后对照原文自查所有数字和公式是否准确

输出路径：[请指定输出文件路径]
```

## 配套工具

如果需要从 PDF 自动提取文本供 AI 分析，可以先使用以下命令提取论文内容：

```bash
# macOS 使用 pdftotext（需安装 poppler）
pdftotext -layout paper.pdf paper_text.txt

# 或使用 Python
python3 -c "
import pdfplumber
with pdfplumber.open('paper.pdf') as pdf:
    for i, page in enumerate(pdf.pages):
        print(f'=== Page {i+1} ===')
        print(page.extract_text())
" > paper_text.txt
```

然后将 `paper_text.txt` 的内容连同上述提示词一起发送给 AI。
