## 一、全栈工程师技术路线图

### 1. 前端技术

**基础三件套**
- HTML5 / CSS3 / JavaScript (ES6+)
- 响应式布局、Flexbox、Grid

**框架选择（选一个精通）**
- React + Next.js
- Vue.js + Nuxt.js

**必备技能**
- TypeScript
- 状态管理（Redux / Zustand / Pinia）
- CSS 预处理器（Sass/Less）或 框架（TailwindCSS）
- 构建工具（Vite / Webpack）

---

### 2. 后端技术

**语言选择（选1-2门精通）**
- Node.js (Express / Nest.js / Fastify)
- Python (Django / FastAPI)
- Java (Spring Boot)
- Go

**核心概念**
- RESTful API / GraphQL
- 认证授权（JWT、OAuth2）
- 微服务架构基础

---

### 3. 数据库

**关系型**
- PostgreSQL / MySQL

**NoSQL**
- MongoDB / Redis

**必备技能**
- 数据建模
- SQL 优化
- ORM 使用（Prisma / TypeORM / Sequelize）

---

### 4. DevOps & 部署

- Git 版本控制
- Docker 容器化
- CI/CD（GitHub Actions / GitLab CI）
- 云平台（AWS / Vercel / Railway）
- Nginx 基础配置

---

### 5. 推荐学习路径

```
阶段1: 前端基础 (1-2个月)
    → HTML/CSS/JS + 一个框架

阶段2: 后端入门 (1-2个月)
    → Node.js 或 Python + 数据库

阶段3: 全栈项目 (1-2个月)
    → 完整项目：用户认证 + CRUD + 部署

阶段4: 深入提升 (持续)
    → 性能优化 / 架构设计 / DevOps
```

### 目标项目：自动驾驶定位数据可视化平台

**核心功能：**
- 轨迹回放与可视化
- 传感器数据实时展示（GPS/IMU/LiDAR）

### 推荐开源项目（源码学习）

| [Foxglove Studio](https://github.com/foxglove/studio) | 机器人/自动驾驶可视化平台 | 架构设计、数据流处理、3D可视化 |

### 分阶段实现计划

#### 阶段1：基础框架搭建（2-3周）

**目标：** 建立项目骨架，跑通前后端

**前端初始化：**
```bash
# 使用 Next.js 全栈框架
npx create-next-app@latest localization-viz \
  --typescript --tailwind --app
```

**后端选择（二选一）：**

| 方案 | 优势 | 推荐场景 |
|-----|------|---------|
| **Python FastAPI** | 算法集成方便 | 快速开发 |
| **Go** | 性能优秀，C++背景友好 | 高性能需求 |

**学习任务：**
1. 阅读 Foxglove Studio 的项目结构
2. 学习 Kepler.gl 的 Mapbox 集成方式
3. 完成基础布局：地图 + 侧边栏 + 图表面板

---

#### 阶段2：核心功能开发（3-4周）

**模块1：轨迹可视化**
- 学习源码：Kepler.gl 的轨迹渲染
- 实现：GPS点在地图上绘制轨迹线

**模块2：数据回放控制**
- 学习源码：Webviz 的时间轴组件
- 实现：播放/暂停/进度条/倍速

**模块3：图表展示**
- 学习源码：PlotJuggler 的实时图表
- 实现：定位误差曲线、速度图表

---

#### 阶段3：数据流处理（2周）

**实时数据接入**
- WebSocket 实时推流
- MQTT 消息订阅（自动驾驶常用）

**数据存储**
- TimescaleDB 存储时序数据
- PostgreSQL 存储轨迹元数据

---

#### 阶段4：高级特性（持续迭代）

- 3D 点云显示（Three.js）
- 多车轨迹对比
- 定位算法在线评估
- 数据导出与分析报告

---
